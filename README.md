# BITASEC — Best Information Technology Advanced Security

Professional corporate technology-services website starter.

## Architecture

- `frontend/` — public website interface and static assets
- `backend/` — Django application and business logic
- `database/` — database scripts, schema notes, migrations guidance
- `docs/` — architecture, security and deployment documentation

## Planned services

1. Cybersecurity
2. Networking & IT Infrastructure
3. IoT & Smart Homes
4. Artificial Intelligence
5. Electrical Engineering
6. Training & Conferences

## Development order

1. Build and approve the frontend design.
2. Build Django backend APIs/pages.
3. Connect PostgreSQL.
4. Add contact/service-request forms.
5. Add admin management.
6. Harden security.
7. Deploy layers separately.

## Important

Do not put production passwords, API keys, database credentials, private certificates,
or `.env` files containing secrets into this repository or ZIP package.
